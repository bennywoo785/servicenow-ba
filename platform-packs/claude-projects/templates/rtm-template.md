# 需求追溯矩阵（RTM, Requirement Traceability Matrix）

> 用途：保证每条业务需求可追溯到底——BRD → FRD → 用户故事 → 测试用例，无遗漏无孤儿。

| BRD 编号 | 业务需求 | FRD 编号 | 功能规格 | 用户故事 | 测试用例 | 状态 | 备注 |
|---|---|---|---|---|---|---|---|
| BR-001 | | FR-001 | | US-___ | TC-___ | 未开始/开发中/测试中/已验收 | |

## 使用规则
- 每新增一条 BRD 需求，立即建立本行，后续列随阶段推进补齐
- 任何测试用例找不到上游需求 = 范围蔓延信号，立即核查
- 任何需求没有测试用例 = 验收风险，UAT 前必须补齐
- 状态每周更新，作为项目周报附件
