## 2. 功能需求明细
每条对应 BRD 条目，展开为 ServiceNow 可实现的功能规格。

| 字段 | 说明 |
|---|---|
| 需求编号 | FR-001（对应 BR-001） |
| 功能描述 | 一句话描述 |
| 触发器（Trigger） | 什么条件下触发（表/事件/定时） |
| 动作（Action） | 系统执行什么 |
| 时序（Timing） | 时限要求（如 ≤5 分钟） |
| 涉及字段/变量 | 列出表单字段（变量名、类型、必填、校验） |
| OOTB 还是定制 | ☐ OOTB ☐ 配置 ☐ 定制代码（定制须写明理由与代价） |
| 权限（RBAC） | 哪些角色可见/可操作 |
| 通知 | 触发点、模板、收件人 |
| 验收标准 | 可测试的判定条件 |
